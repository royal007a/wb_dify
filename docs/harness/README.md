# Hify Engineering Harness

本目录保存稳定制度；机器状态只保存在 `harness/tasks.json` 与 `harness/state.json`，人类进度页 `harness/progress.md` 由程序生成。不得在文档中维护第二份任务状态。

- 产品与非目标：`PRODUCT_SCOPE.md`
- 组件和数据流：`ARCHITECTURE.md`
- 业务域到验证范围：`DOMAIN_MAP.md`
- 状态、命名和协作约定：`CONVENTIONS.md`
- 质量门禁与 DoD：`QUALITY.md`
- 权限、安全与证据数据：`SECURITY_AND_DATA.md`
- 初始化、运行、恢复和故障处置：`OPERATIONS.md`
- 有效技术决策索引：`TECH_DECISIONS.md`
