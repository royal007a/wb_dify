# Chat UI 生命周期与恢复

只处理 A08，不新增历史管理/鉴权/模型能力。生产 API 不变，受控前端测试不冒充服务端验证。

1. Playwright 通过显式 Fake EventSource 与 mock HTTP 复现：执行时新会话可点击；终态回读失败卡住；离页不关闭；终态文本不对账；取消错误无提示。
2. 页面持有事件源与代际标记；执行时禁止新会话，退出时清理；同事件id去重。
3. 终态回读失败保留错误与重试同步按钮；连接出错时有限次状态回读，已终态则收敛，未终态不假完成；用户仍可取消。
4. 最终持久化输出为准，修正部分流文本；不通过自动重发用户消息来恢复。
5. 单独端口 Vite + 浏览器控制测试，typecheck/build；停止本任务的Vite，不操作已有服务。后续真实Chat/PG矩阵另验。
